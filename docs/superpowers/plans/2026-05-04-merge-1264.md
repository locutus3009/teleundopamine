# Merge Upstream release-12.6.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring `nerovny/detox` from upstream Telegram Android 12.5.1 (build 6580) to 12.6.4 (build 6666) while preserving all 32 `// CUSTOM:` blocks across 10 files. Verification is code-level only; the user runs the build and on-device test pass after sub-projects A, B, and C all land.

**Architecture:** Single merge commit on `nerovny/detox` (no worktree, no rebase). Approach **M2 — verify-during-resolve**: re-anchor displaced custom blocks in the same commit as the conflict resolution, rather than fixing drift in a follow-up commit. One follow-up commit updates CLAUDE.md (version bump + post-merge verification pointer).

**Tech Stack:** Git merge, Java/Kotlin source review, grep-based behavior cross-check. No build/test runtime in this sub-project.

**Spec:** `docs/superpowers/specs/2026-05-04-merge-1264-design.md`

**Inventory baseline (pre-merge):**
- 32 `// CUSTOM:` markers across 10 files
- Per-file counts: `ChatActivity.java` 7, `MessagesController.java` 7, `BuildVars.java` 4, `ProfileActivity.java` 3, `DialogsSearchAdapter.java` 3, `LaunchActivity.java` 2, `DialogsChannelsAdapter.java` 2, `SearchAdapterHelper.java` 2, `PostsSearchContainer.java` 1, `HashtagsSearchAdapter.java` 1

---

## Resolution rules (referenced by every conflict task)

- **(a) Default: take both** — keep upstream changes AND custom logic.
- **(b) Method renamed/split** — re-anchor the custom block to the equivalent user-facing flow in the new code. Add a one-line comment: `// CUSTOM: <feature> (relocated from <old> — upstream split into <new> in 12.6.x)`.
- **(c) Method removed entirely** — mark in `MERGE_INVENTORY.md` as **REMOVED**. Stop the task and ask the user.
- **(d) Custom block redundant** (upstream added equivalent restriction) — keep our block anyway.
- **(e) TL schema shape changed** — annotate with `// MERGE-FLAG: verify TL shape <type>`. Do not speculatively fix.
- **(f) Re-read the whole file** after resolving its conflicts.
